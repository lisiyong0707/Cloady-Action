# Cloady 保活 Worker + Web 控制面板 (多节点版)

基于 Cloudflare Workers 构建的自动化节点保活工具，自带简洁优雅的 Web 控制面板（自适应暗色模式），专为 PaaS 容器平台（如 Koyeb、Render 等）上的节点防休眠保活设计。

---

## ✨ 核心特性

- 🌐 **三层深度保活检测**：
  1. **根路径探测**：发送 HTTP GET 请求，唤醒基础 Web 容器服务。
  2. **WebSocket 握手**：发送协议升级请求，验证 101 Switching Protocols 握手。
  3. **流量消耗（可选）**：支持自定义下载指定大小（MB）的文件，防止平台因“零流量”判定闲置。
- 🔒 **隐私与安全**：
  - 支持直接粘贴 `vless://` 链接，脚本**仅提取 Host、Path 与传输类型，UUID 绝对不入库**。
  - 控制面板使用 Cookie + SHA-256 哈希鉴权，单密码安全登录。
- 📊 **可视化 Web 管理**：
  - 支持最多添加 10 个独立节点。
  - 自动记录并展示最近 15 次执行日志及各个步骤的状态码。
  - 内置账号备忘录，明文记录账号邮箱、容器到期时间等信息。
  - 单文件开箱即用，零外部资源依赖，自适应手机端与暗色模式。
- ⚡ **CF 额度保护**：内置子请求预算控制（上限 45 次），防止超出 Cloudflare 免费版单次 Worker 50 次子请求配额。

## 🚀 部署步骤

### 第一步：创建 KV 命名空间
1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)。
2. 进入 **Workers 和 Pages** -> **KV**。
3. 点击 **创建命名空间**，命名为 `CLOADY_KV`（名称可自定义）。

### 第二步：创建 Worker 并配置代码
1. 进入 **Workers 和 Pages** -> **创建应用程序** -> **创建 Worker**。
2. 命名后点击 **部署**。
3. 进入代码编辑页面，将项目脚本完整覆盖至编辑器中，点击 **保存并部署**。

### 第三步：配置变量与绑定 (重要)
进入该 Worker 的 **设置 (Settings)** 页面：

1. **绑定 KV 命名空间**：
   - 进入 **变量 (Variables)** -> **KV 命名空间绑定** -> 点击 **添加绑定**。
   - **变量名称** 必须严格填写：`KV`
   - **KV 命名空间** 选择第一步创建的命名空间。
2. **设置登录密码 (Secret)**：
   - 在 **环境变量** 中，点击 **添加**。
   - **变量名称** 填写：`PANEL_KEY`
   - **值** 填写你想要设置的面板登录密码。
   - 点击 **加密 (Encrypt)** 并保存。

### 第四步：设置定时触发器 (Cron Triggers)
1. 进入 Worker 的 **触发器 (Triggers)** 页面。
2. 找到 **Cron 触发器** -> 点击 **添加触发器**。
3. 根据目标平台的休眠规则设置执行周期，例如：
   - 每 3 天执行一次：`0 0 */3 * *`
   - 每天中午 12 点执行一次：`0 12 * * *`
   - 每 12 小时执行一次：`0 */12 * * *`

## 🛠️ 使用指南

### 1. 登录面板
访问你的 Worker 域名（如 `https://your-worker.workers.dev`），输入 `PANEL_KEY` 中设置的密码即可进入面板。

### 2. 添加节点
1. 复制完整的 `vless://` 节点链接。
2. 粘贴至面板的 **添加节点** 文本框，可自定义命名。
3. 点击添加，系统会自动提取 `Host` 与 `Path`，**UUID 会被自动丢弃**。

### 3. 配置流量保活（可选）
某些平台对流量有活跃度检测：
1. 点击节点卡片中的 **流量与改名（可选）** 折叠菜单。
2. **流量文件地址**：填入一个直链文件/测速文件地址（如 `https://你的节点域名/test.bin`）。
3. **每次下载 MB**：设置单次保活下载的目标流量（0-50 MB，填 0 即关闭该层）。
4. 点击 **保存**。

### 4. 手动调试
点击面板中的 **立即运行** 按钮，会立即触发一次全节点保活任务，页面刷新后可在 **最近记录** 中查看各个节点的执行结果与详细日志。

## ⚠️ 参数与配额说明

| 参数项 | 默认上限 | 说明 |
| :--- | :--- | :--- |
| **最大节点数** | 10 个 | 受限于免费版 Worker 资源及请求限制。 |
| **子请求预算** | 45 次 | 免费版单次 Worker 最大允许 50 个子请求，留有 5 次冗余余量。 |
| **单节点流量** | 50 MB | 避免流量过大导致 Worker 超过 CPU 执行时间或超时限制。 |
| **日志保留** | 15 条 | 最新的记录会存入 KV，自动清理旧记录。 |

> **提示**：若添加的节点传输协议非 `ws`（如 `gRPC`、`TCP` 原生），面板将展示黄色提示。此时 WebSocket 握手步会标记失败，但**根地址探测**与**流量层**仍会正常运行。
